    The library

    Dependency-free C++17. Each category is a table of its data items; one bounds-checked engine decodes all of them, so malformed input is reported, never read out of bounds. Source code

    In this page

    Emscripten compiles the same C++ sources to JavaScript. The page carries the compiled decoder, so decoding happens on your device. Its output is byte-identical to the native build.

    Verified

    62 unit tests, 60,000 random records compared field by field with libasterix, a real radar recording checked against two independent decoders, and 1.6 million fuzzed inputs without a crash.

    Supports CAT048 edition 1.32, CAT034 edition 1.29 and CAT063 edition 1.7, plus their earlier compatible editions. The demo radar feed is synthetic: fictional flights generated for this page.
